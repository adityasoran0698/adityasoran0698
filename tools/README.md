# README artwork generator

Theme: "Moonlit Sage" (dark) / "Morning Sage" (light).
Fonts: Fraunces (headings, soft serif) and Manrope (body), both SIL Open Font License.

Every SVG in `../assets` is generated by `build.py`. Text is converted to vector
outlines, so it renders in these fonts on GitHub, which blocks web fonts inside images.

## Update the artwork

1. Edit the content at the top of `build.py`: HEADER, ROLES (experience),
   PROJECTS, ACHIEVEMENTS. Colours live in `THEMES` inside `engine.py`.
2. Regenerate:

```bash
pip install fonttools brotli
python tools/build.py
```

3. Commit the updated files in `assets/`.
